## CLion开发STM32工程
工程介绍：
- 使用STM32CubeMX生成模板工程
- 开发板使用正点原子的STM32F03ZET6精英开发板

### TIMER
#### 功能描述
- 使用 TIM5_CH1 来做输入捕获，捕获 PA0 上的高电平脉宽，并将脉宽时间通过串口打印出来，然后通过按 WK_UP 按键，模拟输入高电平
- LED0 闪烁指示程序运行。
### 硬件资源
1. LED 灯：
   - PB5引脚接LED0（对应板上灯DS0）
   - PE5引脚接LED1（对应板上灯DS1）
2. 独立按键：WK_UP - PA0
3. 定时器 5，使用 TIM5 通道 1，将 PA0 复用为 TIM5_CH1
