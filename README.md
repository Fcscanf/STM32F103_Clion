## CLion开发STM32工程
工程介绍：
- 使用STM32CubeMX生成模板工程
- 开发板使用正点原子的STM32F03ZET6精英开发板

### TIMER
#### 功能描述
LED0 用来指示程序运行，150ms 变换一次状态，即约 300ms 一次闪烁。不断扫描按键的状态，如果判定了电容触摸按键按下，我们就把 LED1 的状态翻转一次。
#### 硬件资源
1. LED 灯
   - PB5引脚接LED0（对应板上灯DS0）
   - PE5引脚接LED1（对应板上灯DS1）
2. 定时器 5，使用 TIM5 通道 2，将 PA1 复用为 TIM5_CH1
3. GPIO：PA1 用于控制触摸按键 TPAD
