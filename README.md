## CLion开发STM32工程
工程介绍：
- 使用STM32CubeMX生成模板工程
- 开发板使用正点原子的STM32F03ZET6精英开发板

### TIMER
#### 功能描述
1、利用 TIM1_CH1(PE8)输出70%占空比的 PWM 波，它的互补输出通道(PE9)则是输出30%占空比的 PWM 波。
2、刹车功能，当给刹车输入引脚(PE15)输入高电平时，进行刹车，即 PE8 和 PE9 停止输出PWM 波。
3、LED0 闪烁指示程序运行。
#### 硬件资源
1. LED 灯
   - PB5引脚接LED0（对应板上灯DS0）
   - PE5引脚接LED1（对应板上灯DS1）
2. 定时器 1
   - TIM1 正常输出通道 PE9
   - TIM1 互补输出通道 PE8
   - TIM1 刹车输入 PE15
