## CLion开发STM32工程
工程介绍：
- 使用STM32CubeMX生成模板工程
- 开发板使用正点原子的STM32F03ZET6精英开发板

### DMA
通过DMA来实现串口数据传送。  
每按下按键 KEY0，串口 1 就会以 DMA 方式发送数据，打开串口调试助手。  
可以收到 DMA 发送的内容。LED0 闪烁用于提示程序正在运行。
#### 硬件资源
1. LED 灯
  - PB5引脚接LED0（对应板上灯DS0）
  - PE5引脚接LED1（对应板上灯DS1）
2. 独立按键：KEY0 – PE4
3. 串口 1(PA9/PA10 连接在板载 USB 转串口芯片 CH340 上面)
